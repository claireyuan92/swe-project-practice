# Course 5 — Blockchain: Principles to Applications

Rebuild blockchain from first principles — hashes, blocks, proof-of-work,
consensus — then build on it: smart contracts in Solidity, tokens, and a
full-stack dapp.

## Tech stack

Python · Solidity · Ethereum · EVM

## What you build

A simple blockchain from scratch (hashing, mining, chaining, peer validation),
then Solidity smart contracts (ERC-20/NFTs, DeFi basics) and a full-stack
dapp on a local test network.

## Videos

1. **How does a blockchain work – Simply Explained** (~6 min, en, Simply Explained)
https://www.youtube.com/watch?v=SSo_EIwHSd4
Short animated primer on blocks, hashes, hash-chaining, proof-of-work, and distributed consensus — the best first watch.
2. **Blockchain 101 – A Visual Demo** (~18 min, en, Anders Brownworth)
https://www.youtube.com/watch?v=_160oMzblY8
Interactive visual walkthrough of SHA-256 hashing, blocks, mining, chaining, distributed ledgers, and tokens, using a live in-browser demo.
3. **But how does bitcoin actually work?** (~25 min, en, 3Blue1Brown)
https://www.youtube.com/watch?v=bBC-nXj3Ng4
Rebuilds Bitcoin from first principles — ledgers, digital signatures, hash functions, proof-of-work, double-spending — with clear math animations.
4. **零基础初识比特币，实战演示比特币挖矿，新手小白也能看懂的比特币网络运行流程** (zh)
https://www.youtube.com/watch?v=5hgdekVZb3A
Chinese beginner tutorial explaining how Bitcoin works, hashing, and mining, followed by a hands-on demo of building a Bitcoin regtest network and mining/transacting on it.
5. **Solidity, Blockchain, and Smart Contract Course – Beginner to Expert Python Tutorial** (~16 hours, en, freeCodeCamp.org, Patrick Collins)
https://www.youtube.com/watch?v=M576WGiDBdQ
Full hands-on course covering blockchain basics, Solidity, smart contracts, ERC-20/NFTs, DeFi, and full-stack dapp development — the "applications/building" half of the course.

## Docs, articles & repos

- **Intro to Ethereum** (Ethereum Developer Documentation, en)
https://ethereum.org/developers/docs/intro-to-ethereum/
Official technical intro explaining what a blockchain is, how Ethereum works, the EVM, gas, and smart contracts, with links onward to accounts, transactions, and consensus.
- **Blockchain Demo** (interactive, by Anders Brownworth, en)
https://andersbrownworth.com/blockchain/
Hands-on browser demo where you can hash data, mine blocks, tamper with a chain, and watch distributed peers reject invalid blocks — the practical companion to video #2.
- **blockchain-demo** (GitHub repo, en)
https://github.com/anders94/blockchain-demo
Open-source code behind the interactive blockchain demo above — useful as a reference for building a simple blockchain from scratch.
